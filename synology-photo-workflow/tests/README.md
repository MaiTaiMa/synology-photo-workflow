# Tests

Dieser Ordner enthält die automatisierten Qualitäts- und Vertragsprüfungen des Projekts.
Er prüft Konfiguration, Sicherheitsgrenzen, Archivierung, Recovery, Skripte und die NAS-Struktur.

## Abgrenzung

- `tests/integration/` enthält optionale Integrationsprüfungen.
- Die regulären Tests bleiben schnell und standardmäßig auszuführen.
- Hier liegt keine Laufzeitlogik des Produkts.
